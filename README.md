## Instrucciones para el asistente

1. Leer [INSTALAR.md](INSTALAR.md) antes de actuar.
2. Descargar el archivo **edicion-territorio-america.zip** de Releases. El ZIP automático **Source code** solo contiene estas guías y no es la skill completa.
3. Extraer en una carpeta temporal y verificar `MANIFEST.sha256.json`.
4. Determinar la carpeta de skills compatible con el entorno y ejecutar el instalador con `--skills-dir` apuntando a ella. Preservar versiones anteriores.
5. Comprobar los archivos y la detección por el entorno antes de anunciar que está instalada.

La guía detalla las rutas, requisitos y comprobaciones. La documentación de [skills locales de Codex](https://learn.chatgpt.com/docs/build-skills) explica su instalación y detección.

Este repositorio comparte exclusivamente Territorio América. El paquete incluye fuentes, PDF, referencias, presets e instalador; los demás respaldos de Maka permanecen privados.
